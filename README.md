This repository is the official Homebrew tap for [**Yamlr**](https://github.com/yamlr/yamlr) — the Autonomous Kubernetes Manifest Healing & Schema Enforcement Engine.

---

## 🍺 Installation

Install `yamlr` directly via Homebrew on macOS (Apple Silicon & Intel) or Linux (x86_64):

```bash
# 1. Add the official Yamlr tap
brew tap yamlr/tap

# 2. Install Yamlr
brew install yamlr
```

Alternatively, install in a single command:
```bash
brew install yamlr/tap/yamlr
```

---

## 🔄 Upgrading

Keep your Yamlr CLI updated to the latest schema rules and healing heuristics:

```bash
brew update
brew upgrade yamlr
```

---

## ⚡ Verification

Verify the installed binary:

```bash
yamlr --version
yamlr --help
```
